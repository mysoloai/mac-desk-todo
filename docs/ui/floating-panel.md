# 浮窗与设置页视觉/交互规范

## 尺寸与布局

| 项 | 值 |
|---|---|
| 浮窗尺寸 | 默认 400 × 264 pt（可在 340 × 200 以上自由拖拽缩放），圆角 16 |
| 默认位置 | 屏幕左侧、上沿距顶 24pt；位置与尺寸都持久化，下次原样恢复 |
| 顶部浮层 | 距边 8，高 32，圆角 11；6 个 tab 字号 11 |
| 列表滚动区 | 从 y=46 开始，不侵入顶部浮层 |
| 行内左留白 | 圆圈 x=34，直径 16；文字 x=62，右留白 16 |
| 行距 | 文字高 + 9（不再为时间戳留空，行更紧凑） |
| 日期 | 不在行内常驻；鼠标停在圆圈上时，圆圈左侧弹出气泡显示 `yyyy-MM-dd HH:mm:ss` |
| 透明度 | 不再放浮窗上；改由设置页的横向滑条控制（0.30–1.00） |

## 窗口层级

- 「浮窗始终置顶」**默认关闭**：浮窗处在普通窗口层级（`level = .normal`、`isFloatingPanel = false`），不压住其他应用的窗口。
- 设置页打开后 `level = .floating` + `isFloatingPanel = true`，浮在其他窗口之上；切换由 `AppSettings.didChange` 即时生效，不用重开浮窗。
- 两种层级下 `hidesOnDeactivate = false`：应用失活（点了别的应用）浮窗不会自己消失。

## 主题与颜色

- 主题三档：跟随系统（默认）/ 浅色 / 深色。跟随系统时读取 `NSApp.effectiveAppearance`，系统切深浅后浮窗自动重绘。
- 浅色主题底色 `#F6F5F2` 暖白（纯白在桌面上太扎眼）；深色主题底色 `#1F1F22`，文字自动切成浅色。
- 色板（10 预设 + 圆盘自定义）优先于主题：挑过任意底色即为「自定义底色」，主题分段显示为未选中；再点任一主题会回到该主题底色。
- 底色：用户选择的颜色（10 预设 + 自定义），深色底自动把文字切成浅色（亮度阈值 0.45）。
- 文字：深底 `#F5F5F7` / 浅底 `#1F1F21`；次要文字透明度 0.45–0.55。
- 边框：浅底黑 12% / 深底白 16%，1pt 描边。

## 交互

- 悬停窗口：显示顶部 tab + 关闭按钮；离开且不在编辑时隐藏（左侧不再有透明度竖条，行首留白专用于圆圈）。
- 顶部 tab：待完成/全部/已完成/今日/前一日/后一日，选中项为实底胶囊。
- 关闭按钮：`orderOut`，最小化到菜单栏；⌥⌘N 或左键点菜单栏图标再唤出。
- 圆圈：空心 → 点击变实心（文字色）+ 白色对钩；已完成条目文字加删除线并转次要色。
- 行内点击（非圆圈）：进入编辑，光标置于末尾；Esc 结束编辑；Enter 提交并直接起下一条（不插入换行）；长文本只自动折行。
- 空白处单击：新建空条目并进入编辑；空内容失焦自动删除；按住拖动移动浮窗。
- 边缘缩放：贴住窗口边缘 7pt 内按下拖拽即改尺寸（borderless 窗口没有系统缩放边框，由 `ResizeEdgeView` 接管），光标在边缘变双向箭头。
- 日期气泡：独立小窗口画在浮窗之外，所以气泡可以出现在圆圈左侧而不挤占卡片；滚动、切视图、进入编辑、鼠标离开都会收起。
- 透明度：只能在设置页调节（拖动实时改窗口 alpha，0.30–1.00），浮窗上没有任何透明度控件。

## 设置页

- 尺寸 460 × 818；标题 20pt，分节标题 12pt semibold。
- 分节顺序：主题（分段控件）→ 浮窗颜色（色板 + 自定义）→ 透明度（滑条 + 百分比）→ 浮窗显示（两个勾选框）→ 字号（滑条 + 样例）→ 启动与程序坞（两个勾选框）。
- 色球直径 26、间距 12；选中环画在球内（浅色用深环、深色用白环）。
- 字号滑条 12–30，右侧「NN pt」；样例框 404 × 132，圆角 12，文案「这是一条字体大小测试文字」按当前字号居中。
- 「浮窗显示」分节：勾选框「允许用鼠标拖拽调整浮窗大小」（默认勾），勾选后浮窗四周 7pt 内可拖拽缩放，取消后恢复固定尺寸；勾选框「浮窗始终置顶（悬浮在其他窗口之上）」（默认不勾）。

## 视图默认值

- 默认停在「今日」；用户切到其他视图后记住选择，下次呼出沿用上次的视图。
- 悬浮控件（tab 组 + 关闭按钮 + 左侧透明度竖条）仅在鼠标进入浮窗或正在编辑时出现，离开后淡出。

## 离屏渲染基线
